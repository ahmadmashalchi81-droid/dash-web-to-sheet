## ۱. اقدامات انجام‌شده در فاز ۱

1. **اتصال مستقیم به `WEB_APP_URL` از بخش Secrets:**
   - سرور پشتیبان با استفاده از متغیر محیطی امن `process.env.WEB_APP_URL` به صورت خودکار آدرس Google Apps Script Web App پروژه را واکشی و در پیکربندی پایپ‌لاین مستقر کرد.
   - وضعیت پروب سلامت نشان داد که وب‌سرویس با وضعیت `200 OK` و شناسه سرویس `Ammar Documentary Registration Web App API v2.0.0` متصل و فعال است.

2. **راه‌اندازی پایپ‌لاین پشتیبان داخلی با صفحه‌بندی (Pagination):**
   - ایجاد اندپوینت اختصاصی `GET /api/v1/documentaries` با پشتیبانی کامل از پارامترهای صفحه‌بندی:
     - `page`: شماره صفحه جاری
     - `limit`: تعداد آیتم در هر صفحه (پیش‌فرض ۱۰، قابل انتخاب ۵، ۱۰، ۲۰، ۵۰)
   - ساختار خروجی آرایه‌ای استاندارد شامل:
     - `success: true`
     - `pagination`: حاوی `page`, `limit`, `total`, `totalPages`, `hasNextPage`, `hasPrevPage`
     - `data`: آرایه مستندها منطبق با ۳۲ فیلد ریشه، ۴ آرایه ساده، ۲۵ عنوان شغلی عوامل، جدول مصاحبه‌ها و خط زمان موسیقی
     - `kpis`: مجموع زمان فرمت‌شده (`X ساعت و Y دقیقه`)، میانگین امتیاز گفتمان عمار و نسبت آثار تایید شده

3. **پیاده‌سازی متد `POST` برای ثبت و الحاق داده‌ها:**
   - مطابق بخش مشخصات وب‌سرویس پایه نقشه راه، اندپوینت `POST /api/v1/documentaries` در بک‌اند تعبیه شد تا اطلاعات ارسالی مستند جدید را پس از اعتبارسنجی اسکیما، از طریق متد `POST` مستقیماً به آدرس `WEB_APP_URL` گوگل شیت ارسال و ذخیره کند.
