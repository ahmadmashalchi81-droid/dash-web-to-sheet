# 🎯 شرح و فرآیند عملیاتی پروژه DocuSheet API (اصلاح‌شده)

## ۱. شرح و جریان فرآیند (Workflow Process)
پروژه **DocuSheet API** یک راهکار مکانیزه برای انتقال و نمایش شناسنامه مستندها است. فرآیند کاری سیستم دقیقاً به شرح زیر است:

1. **بارگذاری توسط اپراتور:** اپراتور فایل JSON حاوی اطلاعات و متادیتای استخراج‌شده مستند را در پنل داشبورد وب آپلود می‌کند.
2. **ارسال به API:** داشبورد وب این فایل JSON را بدون تغییر و به صورت یک درخواست متد `POST` به سمت API گوگل اپس اسکریپت (Apps Script) ارسال می‌کند.
3. **ثبت در گوگل شیت:** گوگل اپس اسکریپت درخواست را دریافت، پارس و ساختاردهی کرده و بدون تداخل فیلدها، آن را به عنوان یک ردیف جدید به فایل گوگل شیت (Google Sheets) متصل به خود اضافه می‌کند.

---

## ۲. هدف پروژه (از نظر تبادل داده)
* **ثبت داده‌ها (Write):** انتقال خودکار و هوشمند فایلهای JSON آپلود شده توسط اپراتور به گوگل شیت از طریق وب‌اپ اسکریپت.
* **خواندن داده‌ها (Read):** فراخوانی و خواندن تمام اطلاعات موجود در گوگل شیت توسط اپس اسکریپت و ارسال آن به داشبورد وب جهت رندر کردن جدول اصلی، اعمال فیلترها و محاسبه کارت‌های شاخص (تعداد کل آثار، مجموع زمان و...).

---

## ۳. ذینفعان و بخش‌های درگیر
* **اپراتور سیستم:** مسئول آپلود فایلهای شناسنامه (JSON).
* **داشبورد وب (رابط کاربری):** واسط دریافت فایل از اپراتور، ارسال آن به واسط گوگل و نمایش گزارش‌های دریافتی از شیت.
* **گوگل اپس اسکریپت (بک‌اند/واسط):** مغز متفکر پروژه که وظیفه نوشتن و خواندن داده‌ها از دیتابیس (Google Sheets) را بر عهده دارد.
